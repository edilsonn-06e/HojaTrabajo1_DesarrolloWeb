# Hoja de Trabajo 2 - Desarrollo Web

## Descripción del proyecto

Este proyecto corresponde a la segunda fase del desarrollo de la página web sobre la excursión turística a **Semuc Champey**. En esta versión se incorporó una hoja de estilos en **CSS3** para mejorar la presentación visual del sitio, aplicando un diseño responsivo y una mejor organización del contenido, manteniendo la estructura desarrollada en HTML5.

## Mejoras implementadas

- Incorporación de una hoja de estilos externa (CSS3).
- Diseño responsivo para diferentes tamaños de pantalla.
- Mejora en la distribución y organización del contenido.
- Estilización del encabezado y menú de navegación.
- Diseño de la galería de imágenes.
- Personalización de la tabla del itinerario.
- Estilos para listas, enlaces y pie de página.
- Definición de una paleta de colores inspirada en el entorno natural de Semuc Champey.
