# Hoja de Trabajo 2 - Desarrollo Web

## Descripción del proyecto

Este proyecto corresponde a la segunda fase del desarrollo de la página web sobre la excursión turística a **Semuc Champey**. En esta versión se incorporó una hoja de estilos en **CSS3** para mejorar la presentación visual del sitio, aplicando un diseño responsivo, una mejor distribución de los elementos y una apariencia más organizada, manteniendo la estructura desarrollada en HTML5.
