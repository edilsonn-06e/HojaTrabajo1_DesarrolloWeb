# Hoja de Trabajo 1 - Desarrollo Web

## Descripción del proyecto

Este proyecto consiste en una página web informativa desarrollada únicamente con HTML para promocionar una excursión turística a **Semuc Champey**, uno de los destinos naturales más representativos de Guatemala. La página incluye una descripción del lugar, una galería de imágenes, un itinerario de la excursión, una lista de actividades y un pie de página con la información del estudiante.
