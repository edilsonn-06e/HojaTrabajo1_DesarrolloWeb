# Hoja de Trabajo 3 - Desarrollo Web

## Descripción del proyecto

Este proyecto corresponde a la tercera fase del desarrollo de la página web sobre la excursión turística a **Semuc Champey**. En esta versión se incorporó **JavaScript** mediante un archivo externo para agregar interactividad al sitio web, permitiendo la manipulación del DOM y la respuesta a diferentes eventos realizados por el usuario.

Se mantiene la estructura desarrollada con **HTML5** y el diseño responsivo implementado con **CSS3**, incorporando nuevas funcionalidades que mejoran la experiencia de navegación del visitante.

## Nuevas funcionalidades implementadas con JavaScript

* **Galería de imágenes interactiva:** al hacer clic sobre una imagen de la galería, se muestra en un visor o modal en tamaño ampliado junto con su descripción. El usuario puede cerrar el modal mediante un botón.

* **Calculadora de cotización:** permite ingresar el número de asistentes, seleccionar un tipo de paquete y agregar servicios adicionales mediante casillas de verificación. JavaScript calcula y muestra el precio total estimado sin recargar la página.

* **Buscador de actividades:** se agregó un campo de búsqueda que permite filtrar en tiempo real las actividades disponibles según el texto ingresado por el usuario.

* **Reservación interactiva:** se incorporó un formulario que valida que los campos requeridos estén completos antes de registrar la solicitud. Al completar correctamente la información, se muestra un mensaje dinámico de confirmación con el nombre del visitante y la cantidad de personas.

* **Reseñas aleatorias:** se agregó una sección de opiniones de visitantes utilizando arreglos de nombres y comentarios. Mediante JavaScript se seleccionan y muestran testimonios de forma aleatoria.

## Características técnicas de JavaScript

* Uso de un archivo JavaScript externo (`app.js`).
* Selección de elementos mediante `getElementById()` y `querySelectorAll()`.
* Manejo de eventos mediante `addEventListener()`.
* Manipulación del contenido de los elementos del DOM.
* Uso de `.classList` para agregar y eliminar clases CSS.
* Uso de arreglos (`arrays`) para almacenar nombres y testimonios.
* Uso de funciones para organizar las diferentes funcionalidades.
* Actualización dinámica del contenido sin necesidad de recargar la página.

## Mejoras implementadas anteriormente
